# `tools/`

Non-C++ helper scripts: fixture fetching, schema sync, CI glue, repo lint.

| Tool | Milestone | Purpose |
|------|-----------|---------|
| `lint/check-determinism.sh` | M0 (present) | Repo policy checks a compiler cannot make: banned RNGs, banned float flags, raw `%` / `>>` on signed values |
| `lint/format.sh` | M0 (present) | `clang-format` check / apply over first-party sources |
| `vectors/JavaMathVectors.java` | M1 (present) | Emits `tests/unit/javamath_vectors.inc`: known-answer vectors for `stratum::javamath`, observed from a real JVM. CI re-runs it and fails on any diff |
| `vectors/JavaRandomVectors.java` | M1 (present) | Emits `tests/unit/java_random_vectors.inc`: known-answer vectors for `stratum::rng::JavaRandom` from `java.util.Random`, floats as raw bit patterns |
| `vectors/StrictMathVectors.java` | M1 (present) | Emits `tests/unit/fdlibm_vectors.inc`: `StrictMath.log` known-answer vectors, the oracle for the vendored fdlibm port |
| `vectors/XoroshiroVectors.java` | M1 (present) | Emits `tests/unit/xoroshiro_vectors.inc` from two JDK oracles: `jdk.internal.random.Xoroshiro128PlusPlus` seeded to an exact state, and `RandomSupport.mixStafford13`. Declares its own `--add-exports` flags on a `// JAVA_FLAGS:` line |
| `vectors/generate-md5-vectors.sh` | M1 (present) | Emits `tests/unit/md5_vectors.inc` from `md5sum`, covering RFC 1321's suite, the padding boundaries, and the `octave_*` salts vanilla seeds noise with |
| `vectors/generate-noise-vectors.sh` + `noise_vectors.c` | M1 (present) | Emits `tests/unit/noise_vectors.inc` from cubiomes (MIT) at a pinned commit — fetched, never vendored. Covers the bounded draw, Perlin init and sampling, simplex, octave and normal noise |
| `vectors/generate-climate-vectors.sh` + `climate_vectors.c` | M2 (present) | Emits `tests/conformance/climate_vectors.inc` from the same pinned cubiomes commit, one layer up: the world-seed-to-named-noise derivation, and the overworld's 2D density chain — shift_a/shift_b, flat_cache, shifted_noise and the offset spline. Carries a float-throughout spline reading alongside cubiomes' own, because the two disagree |
| `vectors/generate-blended-vectors.sh` + `blended_vectors.c` | M3 (present) | Emits `tests/unit/blended_vectors.inc` from the same pinned cubiomes commit: the LCG-seeded Perlin construction and the legacy blended noise. Pins the octave loop, the blend and the seeding order — and, deliberately, nothing about `smear_scale_multiplier`, the coordinate wrap or modern seeding, none of which cubiomes models |
| `vectors/generate-nether-vectors.sh` + `nether_vectors.c` | M4 (present) | Emits `tests/unit/nether_climate_vectors.inc` from the same pinned cubiomes commit: `setNetherSeed`'s legacy Nether temperature and humidity over the eight golden seeds. Pins cubiomes' construction only — that vanilla agrees is measured against the golden Nether (SPEC §11) — and not cubiomes' float-distance biome choice, which vanilla's quantised search can contradict at a boundary |
| `vectors/generate-deepslate-vectors.sh` + `deepslate_vectors.mjs`, `deepslate_aquifer_vectors.mjs`, `deepslate_legacy_noise_vectors.mjs` | M3, MA, M4 (present) | Emits `tests/unit/deepslate_vectors.inc`, `tests/unit/deepslate_aquifer_vectors.inc` and `tests/unit/deepslate_legacy_noise_vectors.inc` by running deepslate (MIT) at a pinned npm version as a **black box** — its source is never read (see the provenance rule in `CLAUDE.md`). Fixture-free: the parameters are written in the driver, not read from vanilla's files. Gives `old_blended_noise` an oracle it did not have, and the aquifer's random source an independent check of its base and the position mix's y term — on the y axis only, since deepslate's `PositionalRandom.at` does not wrap the mix and its aquifer does not reproduce the server (`analysis/deepslate-aquifer-trust.sh`, SPEC §11). The third file is not taken as vanilla's: it records deepslate's named noise under `legacy_random_source`, which settled — and withdrew — the legacy tables' "deepslate's own derivation" label (`deepslate_legacy_noise_oracle_test.cpp`, SPEC §11). CI re-runs it and fails on any diff |
| `fetch-vanilla` | M1 (present) | Resolves and verifies the pinned version through Mojang's piston-meta manifest (manifest → metadata SHA-1 → published jar SHA-1 → nested jar SHA-256), downloads or accepts a server jar, and extracts `data/minecraft/worldgen/**`. `--with-structures` also extracts the 1202 vanilla structure `.nbt` files, and does nothing else. `--generate-regions --accept-eula` runs the vanilla server headlessly to produce golden region files for the fixed seed set — frozen, with carvers, features and structures left out, and with a margin so every chunk reaches full status (SPEC §7); `--generate-structures` turns structures on and is refused without `--with-features`, since they are Tier B |
| `mcdoc-sync` | M2 (present) | Fetches SpyglassMC/vanilla-mcdoc (MIT) at a pinned commit, reads the density-function, noise-settings and surface-rule schemas, filters them to the pinned Minecraft version, and generates the C++ tables the loader validates against. The surface-rule half reads three files into one namespace — `material_rule.mcdoc`, `material_condition.mcdoc` and the `mod.mcdoc` that declares the `CaveSurface` and `VerticalAnchor` they use — because mcdoc refers across files by bare name. Fetched, never vendored. The reader is strict: an mcdoc construct it cannot map raises rather than being skipped, because a silently incomplete table would reject datapacks vanilla accepts. Deriving the noise router's field list is not ceremony — at 1.21.9 `initial_density_without_jaggedness` became `preliminary_surface_level`, and a hand-written list would have refused every vanilla settings file |
| `php-dev` | M5 (present) | Builds PHP 8.2.30 thread-safe (the version pmmp/PHP-Binaries pins for PocketMine-MP 5) and pmmp/ext-chunkutils2 0.3.5 from official source into `~/.cache/stratum-php`, no root. PocketMine-MP's own PHP releases ship no headers, so this is what `ext/`'s zend module builds and runs its PHPT tests against. `--print-config` prints the `php-config` path |
| `pmmp-dev` | M5 (present) | A real PocketMine-MP 5.44.3 on PocketMine-MP's own PHP (pmmp/PHP-Binaries php-build-524), for local evidence that `ext/` works inside one. Fetches the release phar and PHP tarball into `~/.cache/stratum-pmmp` (`STRATUM_PMMP_DIR`), refusing either unless its size and SHA-256 are the ones pinned in the script, and unpacks the PHP into a directory of its own once its listing passes: taken once and in full, refused if tar fails or warns, or if a member is absolute, goes through `..`, is a symlink or hard link pointing at an absolute path or through `..`, or is neither file, directory nor link. Nothing from the downloads runs but the php binary and the phar — the php binary meaning the executable, the shared libraries it links from its own `lib/` and the `opcache.so` its own php.ini enables; the PHPTs run under it are driven by tools/php-dev's `run-tests.php`, not the tarball's. `--print-php`, `--print-phar`, `--print-dir` give the paths. `server <dir>` writes a hermetic headless server directory (loopback only; IPv6, Query, UPnP, Xbox Live authentication, crash reports, statistics and update checks off) with the plugin packed into a phar — 5.44.3 has no folder-plugin loader — and the pipeline frozen into the world's folder and named in the world's options relative to the server directory, as the plugin's `WorldFactory` names it, and prints the command that runs it with every path absolute and shell-quoted. It refuses a directory inside the checkout outside `build/` (a frozen pipeline is Mojang-derived, SPEC §12), and every server directory it writes ignores itself; `.gitignore` names `*.blob` and the files it writes as a further guard. For the End it also packs `ext/pocketmine`'s evidence plugin (`plugin.yml`, `src/EvidencePlugin.php`), test tooling only, which sets the new world's spawn to 0 70 0, over the main island, on its `WorldInitEvent`: PocketMine-MP gives every new world 256 70 256, over the End's void; `observe` packs it too, to report from inside the server. Its checks — `check-load` (build ids, the ABI lines of both PHPs, every imported symbol exported, stratum.so beside pmmpthread, chunkutils2, leveldb, igbinary and the rest, and PocketMine-MP's own startup gate, failed too if PHP did not load the module for it), `phpt`, `census-blocks`, `census-biomes`, `threads`, `smoke` (a server boot generating the spawn area, stopped from the console; its network interface on 127.0.0.1 and nowhere else, and no Query listener; then every chunk on disk compared block by block and biome by biome with what the engine generates for it, a spawn area of nothing but air refused, and a block allowed to differ only where PocketMine-MP 5.44.3's own liquid and falling-block rules make it: flowing or falling liquid beside or under the liquid it came from, a water source only beside two others and leading back to the engine's own, stone only beside lava, hardened lava only beside water, a fallen gravel or sand block only over what it could fall into and landing below in its own column — and no more changed blocks in all than four for each fluid position the engine marked for an update in the populated chunks) and `observe` (the overworld smoke watched from inside the server by the evidence plugin: the world's `WorldLoadEvent` fires, the world pinned and none of its chunks loaded, before its first chunk is requested; once the async workers have been idle the 300 s `AsyncPool::shutdownUnusedWorkers()` asks for, the console's `gc` (`MemoryManager::triggerGarbageCollector()`, which the periodic garbage collection runs too) shuts them all down, and the chunks the old workers generated beside the spawn area, populated on new ones together with every chunk within two of them — the plugin releases a chunk's liquids only once those are populated too — get a block update at every fluid position the engine marks in them, from what the pin held; and at every status the evidence plugin asks for, the plugin's fluid scheduler must hold no more chunks than the world has loaded) — are `ctest --preset pmmp`, and each exits 77 (SKIP), saying what is missing, without the cache or the fixtures. `smoke` and `observe` count PocketMine-MP's discarded population results and fail above `--max-discards`, which the CTest cases set to 0. A PHP tree whose unpack marker is not the pinned tarball's digest is refused, and a failed download or unpack leaves nothing behind. The `ext-release` preset builds the stratum.so they load |
| `mapping-sync` | M5 (present) | Fetches GeyserMC/mappings and one Bedrock block palette from GeyserMC/Geyser (both MIT) at the commits Geyser itself shipped for this build's pinned Java version, and generates `lib/mapping/src/biome_table.inc` (Java biome → Bedrock id) and `lib/mapping/src/block_state_table.inc` (Java block state → Bedrock `{name, states, version}`). Needs `tools/fetch-vanilla`'s `worldgen/biome/` and `reports/blocks.json`, and refuses to write a table it could not verify against them: biome coverage, contiguous state ids, one numbering order per block, and every Bedrock state present in the palette. Fetched, never vendored |
| `probe-worlds` | MA (present) | One table of every probe world a committed generator makes for a conformance case, and of the region goldens (`fetch-vanilla --generate-regions` units writing under `regions/`): generator command, outputs and seeds, CI shard. `generate --accept-eula` replaces and checks them, and a generator that fails leaves the outputs it had; `verify` checks seeds, freezing and completeness without a server, and every golden region's 1024 chunks at full status; `key`/`keys` give CI its per-shard cache keys and the tree each shard caches; `lint` fails on a `tools/analysis/*-probe.sh` that is neither a unit nor exempt, a golden unit passing an option that would change what the cases score, or a CI matrix or restore that drifted from the table |
| `check-skips` | MA (present) | CI's conformance skip gate: reads ctest's JUnit report and fails on a case that skipped without a line in `tests/conformance/expected-skips.txt`, or a listed case that ran. ctest counts a skip as a pass |

## Provenance

Nothing these tools download or generate may be committed, or uploaded
from CI as a workflow artifact (SPEC §12). The repo ships scripts; the jar
comes from Mojang, fetched by the user or by CI. See `.gitignore`, which
excludes `.fixtures/`, `*.jar`, `*.mca` and extracted worldgen JSON.
